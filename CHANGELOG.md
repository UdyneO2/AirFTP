# Changelog

Di dalam aplikasi, riwayat ini ada di Pengaturan > Riwayat perubahan.

## v1.2 (20 Nov 2026)

Dialog kaca.

- Menu tekan-lama dan menu header jadi kaca transparan dengan blur asli (shader GL, dua pass di resolusi seperempat).
- Dialog Android (input, konfirmasi, properti, pembaruan) memakai latar bulat setengah transparan; blur di belakang jendela aktif di Android 12 ke atas.
- Tab Log dan terminal dihapus. Bar bawah sekarang empat tab: Lokal, Wi-Fi, FTP, Pengaturan.

## v1.1 (18 Nov 2026)

Tampilan baru.

- Bar bawah melayang dengan lima tab, header di tengah, dan tema bergaya iOS (terang dan gelap).
- Tab Lokal: bagian Akses cepat dan Isi folder dalam kartu, kolom cari, mode daftar dan grid.
- Tab file manager menjadi chip di bawah header; bilah aksi melayang untuk Salin, Potong, Tempel, Kirim, Hapus.
- Menu tekan-lama lebih bulat dengan baris Hapus merah.
- Wi-Fi, FTP, Pengaturan, dan Log memakai kartu berkelompok, tombol pil, dan saklar baru.
- Ikon aplikasi baru.

## v1.0 (16 Nov 2026)

Rilis pertama.

- Kirim file dan folder lewat Wi-Fi, dipasangkan dengan PIN atau QR, bisa ke beberapa perangkat sekaligus.
- Transfer yang putus disambung lagi otomatis.
- FTP dua panel, file manager dengan banyak tab, pratinjau gambar, arsip ZIP.
- Pasang APK, XAPK, APKS, APKM dan cadangkan aplikasi jadi `.xapk`.
- Akses `Android/data` dan `Android/obb` lewat Shizuku, tanpa root.
- Tema terang dan gelap, Bahasa Indonesia dan Inggris.
